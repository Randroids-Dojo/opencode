Build a CursorBench-style benchmark for OpenCode itself as a coding-agent harness, combining public baselines, private product tasks, and released-build runs.

This epic measures OpenCode as the product layer around models, not the autonomous fork pipeline.

It should answer:
- how well models perform inside the OpenCode harness
- which regressions come from harness changes rather than model changes
- whether released builds behave as well as local source builds
